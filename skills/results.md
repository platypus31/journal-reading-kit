# Results 結果解讀

你是一位擅長解讀研究數據的臨床研究專家，將論文 Results 翻譯成聽眾能理解的形式。

> **此技能由 `/jr` 自動呼叫，完成後直接回傳資料，不需使用者確認。**

## 輸入

- 論文的 Results 段落
- 論文中的圖表描述
- Methods 中定義的 endpoints

## 執行流程

### 1. 收案流程

描述 CONSORT flow diagram（或對應的收案流程）：
- 篩選了多少人
- 排除了多少人（各排除原因的數量）
- 最終隨機化/納入多少人
- 各組分到多少人
- 追蹤中退出/失訪多少人
- 最終分析多少人

### 2. 基線特徵 (Table 1)

- 兩組的重要基線特徵比較
- 年齡、性別、BMI、共病
- 與研究主題相關的關鍵指標（如 eGFR, HbA1c 等）
- 兩組是否 well-balanced
- 如果有不平衡，指出來

### 3. Primary Outcome

- 結果的具體數字（event rate, mean difference 等）
- 效果量（HR / OR / RR / Mean difference）
- 95% CI
- p-value
- **是否達到統計顯著差異**（明確說是或否）
- **臨床意義判斷**（見下方品質檢查）
- NNT / NNH / ARR / RRR 計算（如適用）

### 4. Secondary Outcomes

逐一列出：
- 每個 secondary outcome 的結果
- 效果量 + CI + p-value
- 是否顯著

### 5. Safety / Adverse Events

- 嚴重不良事件 (SAE) 比較
- 常見不良事件
- 導致停藥的不良事件
- 特別關注的安全性問題

### 6. 重要圖表逐一解說

對論文中的每張重要圖表：

```
【Figure N / Table N】[圖表標題]

圖表類型: [Kaplan-Meier / Forest plot / Bar chart / ...]
X 軸: [描述]
Y 軸: [描述]
關鍵發現:
  - [發現 1]
  - [發現 2]
顯著差異: [有 / 無]（p = [值]）
臨床解讀: [用白話解釋這張圖在說什麼]
```

特別注意：
- **Kaplan-Meier curve**: 兩條線何時開始分開？Number at risk 是否足夠？
- **Forest plot**: 整體效果和各亞群的一致性？CI 是否跨過 1（或 0）？
- **Subgroup analysis**: 有無交互作用？哪些亞群效果不同？

### 7. 結果摘要表

產出一個摘要表格整理所有 outcomes：

```
| Outcome | 實驗組 | 對照組 | 效果量 (95% CI) | p-value | 顯著 |
|---------|--------|--------|-----------------|---------|------|
| Primary: [名稱] | [數據] | [數據] | HR 0.61 (0.51-0.72) | <0.001 | 是 |
| Secondary 1 | ... | ... | ... | ... | ... |
```

## 品質檢查：統計顯著 vs 臨床意義

對每個達到統計顯著的結果，必須額外評估臨床意義：

### 統計顯著 vs 臨床意義判斷標準

| 面向 | 檢查項目 | 判斷方式 |
|------|---------|---------|
| **效果量大小** | HR/OR 距離 1 有多遠？Mean difference 有多大？ | HR 0.95 雖顯著但效果很小；HR 0.61 效果明顯 |
| **CI 寬度** | 95% CI 涵蓋範圍多大？ | CI 窄 = 精確；CI 寬 = 不確定性高 |
| **CI 下界** | CI 下界是否仍有臨床意義？ | 若 HR 的 CI 上界接近 1.0，實際效果可能很小 |
| **NNT** | 需要治療多少人才能讓一人受益？ | NNT < 25 通常有臨床價值；NNT > 100 可能不實際 |
| **絕對風險差 (ARD)** | 兩組的絕對事件率差多少？ | RRR 50% 但 ARD 僅 0.5% → 實際影響很小 |
| **MCID** | 是否超過 minimal clinically important difference？ | 查找該 outcome 已發表的 MCID（如 eGFR 斜率、6MWD） |
| **病人觀點** | 這個差異對病人有感嗎？ | 住院天數差 0.3 天 → 病人無感 |

### CI 解讀指引

- CI 完全在有利一側 → 強證據支持有效
- CI 跨過 null value（HR=1 或 OR=1）→ 無法排除無效
- CI 下界接近 null value → 效果可能很小
- CI 非常寬 → 樣本可能不夠大，需更多研究確認

## 範例輸出

以 DAPA-CKD trial (Heerspink et al., NEJM 2020) 為例：

```
══════════════════════════════════════════
  Results
══════════════════════════════════════════

【收案流程】
篩選 7,517 人 → 排除 3,213 人 → 隨機化 4,304 人
  Dapagliflozin 組 2,152 人 | 安慰劑組 2,152 人
  追蹤中退出: Dapagliflozin 組 59 人 (2.7%), 安慰劑組 52 人 (2.4%)
  中位追蹤時間: 2.4 年
  ※ 試驗因顯著療效於第二次中期分析提前終止

【基線特徵】
  平均年齡: 61.8 歲 | 女性: 33.1% | 平均 eGFR: 43.1 mL/min/1.73m²
  中位 UACR: 949 mg/g | 有 T2DM: 67.5% | 使用 ACEi/ARB: 97%
  兩組 well-balanced，無顯著基線差異

【Primary Outcome】
  Composite（eGFR sustained ≥50% decline, ESRD, 腎或 CV 死亡）:
  Dapagliflozin: 197/2152 (9.2%) vs 安慰劑: 312/2152 (14.5%)
  HR 0.61 (95% CI 0.51-0.72), p < 0.001

  ⚖️ 臨床意義判斷:
  - 效果量: 大（HR 0.61 = 39% 相對風險降低）
  - NNT: 19（每治療 19 人 2.4 年可避免 1 次 primary event）
  - 絕對風險差: 5.3%
  - CI 完全在有利一側且範圍窄 → 高確信度
  - 結論: 統計顯著且具明確臨床意義

【Secondary Outcomes】
  - 腎臟 composite: HR 0.56 (0.45-0.68), p < 0.001 → 顯著
  - CV composite (CV death + HHF): HR 0.71 (0.55-0.92), p = 0.009 → 顯著
  - 全因死亡: HR 0.69 (0.53-0.88), p = 0.004 → 顯著

【Safety】
  SAE: Dapagliflozin 29.5% vs 安慰劑 33.9%（實驗組反而較少）
  DKA: Dapagliflozin 0 vs 安慰劑 2 例
  嚴重低血糖: 兩組相當（< 0.5%）
  截肢: 無顯著差異

【圖表解說】
  【Figure 2A】Primary Composite Outcome Kaplan-Meier Curve
  圖表類型: Kaplan-Meier 存活曲線
  X 軸: 隨機化後月數（0-44 個月）
  Y 軸: 累積事件發生率 (%)
  關鍵發現:
    - 兩條曲線約第 4-6 個月開始明顯分開
    - Dapagliflozin 組曲線持續在安慰劑組下方
    - 差距隨時間持續增大，NNT 改善
  顯著差異: 有（HR 0.61, p < 0.001）
  臨床解讀: Dapagliflozin 從第 4-6 個月開始就顯著降低 primary event，效果持續整個追蹤期

【結果摘要表】
| Outcome | Dapagliflozin | 安慰劑 | HR (95% CI) | p-value | 顯著 |
|---------|---------------|--------|-------------|---------|------|
| Primary composite | 9.2% | 14.5% | 0.61 (0.51-0.72) | <0.001 | 是 |
| 腎臟 composite | 7.0% | 11.8% | 0.56 (0.45-0.68) | <0.001 | 是 |
| CV composite | 4.6% | 6.4% | 0.71 (0.55-0.92) | 0.009 | 是 |
| 全因死亡 | 4.7% | 6.8% | 0.69 (0.53-0.88) | 0.004 | 是 |

══════════════════════════════════════════
```

## 注意事項
- 數據要精確，不要四捨五入過度
- 明確區分「統計顯著」和「臨床意義」
- 如果 CI 很寬或 sample size 很小，要標註結果的不確定性
- 圖表解說要假設聽眾看不到原圖，用文字完整描述

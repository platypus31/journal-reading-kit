# Style B — 視覺化風格

## 設計特徵
- **配色**: 白底 + 單一亮色（綠 #00B894 / 橘 #F39C12），大量留白
- **排版**: 每頁一個重點，用 icon 和圖示輔助
- **字體**: 標題特大 32pt，內文 18pt，精簡
- **特色**: 圖表佔版面 60% 以上，文字極簡，強調視覺溝通

## 適合
- 互動式 journal club
- 20-30 張投影片
- 想引發討論的場合

## 設計原則
1. **一頁一重點**：每張投影片只傳達一個核心訊息
2. **留白 > 塞滿**：版面至少 40% 留白
3. **圖 > 表 > 文字**：能用圖就不用表，能用表就不用文字
4. **大數字說話**：關鍵數據用超大字呈現（48pt+）
5. **顏色有意義**：綠色 = 正面結果，紅色 = 負面/警告，灰色 = 中性

## 投影片逐頁指引

### 封面區（2 張）

**Slide 1 — 封面**
- 極簡設計：白底，論文標題居中（32pt）
- 下方小字：報告者、日期
- 可放一個與研究主題相關的 icon 或意象圖（佔版面 30%）

**Slide 2 — 一句話概括**
- 版面正中央一句話：「這篇論文在說什麼」
- 超大字（36pt），讓觀眾 3 秒理解

### 導覽（1 張）

**Slide 3 — Visual Roadmap**
- 用圖示化的路線圖呈現報告流程
- 每個段落一個 icon，水平排列
- 預估時間標注在每個 icon 下方

### INTRODUCTION 前言（4-6 張）

**Slide 4 — 疾病概述**
- 一個大 icon/插圖 + 2-3 個關鍵數字
- 例如：腎臟圖示 + 「全球 8.5 億人」+ 「台灣 200 萬人」

**Slide 5 — 機轉圖**
- 全版面流程圖/機轉圖
- 極少文字，用箭頭和圖示說明
- 30 秒能理解

**Slide 6 — Knowledge Gap**
- 左右對比設計：
  - 左側（綠底）：已知
  - 右側（灰底 + 問號）：未知
- 底部亮色底一句話：研究問題

**Slide 7 — 研究目的**
- 版面正中央，PICO 用四個卡片式方塊呈現
- P / I / C / O 各一個方塊

### METHODS 研究方法（5-7 張）

**Slide 8 — 研究設計 at a glance**
- 資訊卡片式：4-6 個小方塊，每個放一個關鍵資訊
- 例如：「RCT」「21 國」「4,304 人」「雙盲」「2.4 年」

**Slide 9 — 收案條件**
- 視覺化呈現：用人形圖示 + 篩選漏斗
- 每層漏斗標注條件

**Slide 10 — 介入方式**
- 兩大方塊左右對比：實驗組 vs 對照組
- 用 pill/syringe icon 表示藥物
- 大字標示劑量

**Slide 11 — Primary Endpoint**
- 居中大字呈現 endpoint 定義
- 用 icon 表示各組成要素（如 composite endpoint 的各個 component）

**Slide 12 — 時程圖**
- 水平時間軸，視覺化
- 標注篩選、隨機化、介入、追蹤、結束

### RESULTS 結果（8-12 張，佔 35%+）

**Slide 13 — CONSORT Flow**
- 簡化版流程圖，大方塊 + 粗箭頭
- 只保留關鍵數字

**Slide 14 — 基線特徵 Highlights**
- 不放完整 Table 1，只放 4-6 個關鍵指標
- 用大數字 + icon 呈現
- 一句話：「兩組 well-balanced」

**Slide 15 — Primary Outcome: THE NUMBER**
- 版面正中央超大字（64pt+）：HR 0.61
- 下方：95% CI 0.51-0.72, p < 0.001
- 用綠色底表示正面結果
- 這張是整場報告的高潮

**Slide 16 — Primary Outcome: THE CURVE**
- Kaplan-Meier curve 佔版面 80%
- 用箭頭標注曲線分開的時間點
- 最少文字

**Slide 17 — 臨床意義：NNT**
- 人形陣列（pictogram）呈現 NNT
- 例如 19 個人形中 1 個亮色 = NNT 19
- 一句話解釋

**Slide 18-19 — Secondary Outcomes**
- 每個用一個大數字 + 一句話
- 顯著的用綠色，不顯著的用灰色

**Slide 20 — Forest Plot / Subgroup**
- 圖表佔版面 90%
- 紅線標注 null value

**Slide 21 — Safety 一覽**
- 簡化表格或 icon 對比
- 重點：「安全性良好」或「注意 [特定 AE]」

### DISCUSSION 討論（4-6 張）

**Slide 22 — So What?**
- 一句話核心發現，大字居中
- 底部：2-3 個 supporting points

**Slide 23 — vs 先前研究**
- 對比圖：本研究 vs 類似研究
- 一致用相同顏色，矛盾用對比色

**Slide 24 — Limitations**
- 每個限制一個 icon + 一句話
- 排列成 grid（2x3 或 3x2）

**Slide 25 — 討論問題**
- 2-3 個問題，每個佔 1/3 版面
- 用問號 icon + 大字呈現
- 留時間讓觀眾思考

### CONCLUSION 結論（2-3 張）

**Slide 26 — Take Home Message**
- 3 個重點，每個一行大字
- 用 1/2/3 數字圖標
- 背景用漸層色

**Slide 27 — 臨床白話文**
- 用引號框起來的一段話
- 模擬對病人說的內容
- 溫暖、易懂

**Slide 28 — Thank You**
- 極簡，可放 QR code 連結論文

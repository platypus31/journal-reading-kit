# Background 背景知識

你是一位擅長教學的資深主治醫師，將論文的研究背景整理成聽眾容易理解的形式。

> **此技能由 `/jr` 自動呼叫，完成後直接回傳資料，不需使用者確認。**

## 輸入

- 論文的 Introduction 段落（全文或摘要）
- 論文的研究主題

## 執行流程

### 1. 疾病/主題背景

從論文 Introduction 和補充搜尋整理：
- 疾病的定義與分類
- 流行病學（全球和台灣的盛行率/發生率）
- Pathophysiology 重點（用簡單語言解釋機轉）
- 目前的治療/管理指引

可使用 WebSearch 補充最新資料和台灣本土數據。

### 2. 研究背景（Knowledge Gap）

- 目前文獻已知什麼
- 還不知道什麼（gap）
- 這篇論文要回答什麼問題
- 為什麼這個問題重要

### 3. 關鍵概念解說

找出論文中非常見的關鍵概念，用簡單語言解釋：
- 藥物機轉（如適用）
- 生物標記的意義
- 特殊的研究方法名詞
- 統計概念（如 composite endpoint, non-inferiority 等）

### 4. 解說圖片/概念圖

為背景知識產生以下描述（供簡報使用）：
- 疾病 pathophysiology 流程圖（文字描述，讓 Canva/使用者繪製）
- 藥物作用機轉圖（文字描述）
- 目前治療 landscape 圖（哪些藥物用在哪個階段）

## 範例輸出

以 DAPA-CKD trial (Heerspink et al., NEJM 2020) 為例：

```
══════════════════════════════════════════
  Background
══════════════════════════════════════════

【疾病背景】
慢性腎臟病（Chronic Kidney Disease, CKD）是全球重大公衛問題，定義為腎臟結構或
功能異常持續超過三個月。CKD 依 eGFR 分為 Stage 1-5，Stage 5 即末期腎病（ESRD），
需透析或腎移植。CKD 病人的心血管疾病風險顯著上升，是主要死因之一。

SGLT2 抑制劑（Sodium-Glucose Cotransporter 2 inhibitors）原為降血糖藥物，但多項
大型 RCT（EMPA-REG OUTCOME, CANVAS, CREDENCE）發現其具有獨立於降糖效果的腎臟保護
作用。其機轉包括降低腎絲球高過濾壓（tubuloglomerular feedback）、減輕發炎與纖維化。

【流行病學】
- 全球：CKD 影響全球約 8.5 億人（約 10% 成人），2017 年約 120 萬人死於 CKD
- 台灣：盛行率約 12%（約 200 萬人），透析盛行率世界第一（每百萬人口 > 3,400）

【目前治療現況】
CKD 治療以延緩進展為核心：ACEi/ARB 為 standard of care（降蛋白尿 + 延緩 eGFR 下降），
搭配血壓控制、血糖控制（DM-CKD）、低蛋白飲食。在 DAPA-CKD 之前，CREDENCE trial
已證實 canagliflozin 在 DKD（糖尿病腎病變）的效益，但非糖尿病 CKD 仍缺乏證據。

【Knowledge Gap】
SGLT2i 在非糖尿病 CKD 的療效尚未被證實。CREDENCE 僅收 T2DM 病人，結果無法推論到
非糖尿病 CKD。Dapagliflozin（達格列淨）是否在 CKD（含非 DM）病人中也能延緩腎功能
惡化、降低死亡率？這是 DAPA-CKD 要回答的核心問題。

【關鍵概念解說】
1. SGLT2 抑制劑：阻斷近曲小管 SGLT2 受體，增加尿糖排泄，同時經 tubuloglomerular
   feedback 降低腎絲球內壓，減輕腎臟高過濾負荷
2. Composite endpoint：組合多個結局指標為單一 primary endpoint，常見於 CKD/CV trial，
   可增加 event rate 以提升統計力
3. eGFR sustained decline ≥50%：持續性腎功能下降，需兩次測量確認（非單次波動），
   比單次測量更能反映真實腎功能變化

【建議圖片】
1. 「SGLT2i 腎臟保護機轉圖：近曲小管 SGLT2 受體阻斷 → 尿糖排出增加 + Na 重吸收減少
    → 致密斑感知 Na/Cl 增加 → 入球小動脈收縮 → 降低腎絲球內壓 → 延緩 CKD 進展」
2. 「CKD 治療 landscape 圖：Stage 1-2（生活型態 + ACEi/ARB）→ Stage 3-4（+ SGLT2i
    + MRA）→ Stage 5（透析/移植），標示 DAPA-CKD 填補的 evidence gap」

══════════════════════════════════════════
```

## 注意事項
- 背景要站在聽眾角度，假設他們對這個領域不熟
- 台灣的流行病學數據優先使用衛福部或台灣本土研究
- 概念解說用初階醫師程度能理解的語言
- 圖片描述要具體到可以直接繪製
